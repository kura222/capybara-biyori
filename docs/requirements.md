## 1. プロジェクト概要

### 1.1 名称（仮）
**カピバラ・ポータル**（正式名称・ドメイン名は仕様フェーズで決定）

### 1.2 目的
- カピバラ好きが「**今すぐカピバラを見たい／会いに行きたい**」を1か所で解決できる日本語Webサービスを、**無料の技術基盤のみ**で構築・運用する。
- アフィリエイト（旅行・チケット・グッズ）を軸に収益化し、成長後に広告（AdSense）を追加する。

### 1.3 背景（リサーチ確定事実）
- カピバラは国内外で本格ブーム中（米CBS「2025年ホリデーのit animal」、カプセルトイ市場2025年約1,960億円・前年比+39%）。
- **「カピバラ特化の集約サービス」は国内外に存在しない**。ライブカメラまとめ系はカピバラ0〜1件、施設一覧系は「網羅×詳細×最新」が揃ったものがない。
- 検索需要が実在する：「カピバラ 温泉 いつから/いつまで」「施設名×温泉」「地域×ふれあい」（7月時点でもサジェスト表示）。上位は2023年の古い記事が残存し、閉園施設すら掲載されたまま。

### 1.4 リサーチによる企画の重要な修正（当初案からのピボット）
当初案「複数のライブカメラをワンタップ切替」は、以下の確定事実により**そのままでは成立しない**：

| 確定事実 | 出典・確認方法 |
|---|---|
| 国内の「固定URL・24時間定点」カピバラ配信は**現在0件** | YouTubeライブ中フィルタ検索＋yt-dlp実測 |
| かつての定点2系統は消滅（アロハガーデンたてやま=2025年3月閉園、東武動物公園=休止） | 閉園報道・livecam.asia |
| 国内の実態は**イベント型配信**（長崎バイオパーク・伊豆シャボテン・池田動物園＝都度URL変更、埼玉こども動物自然公園＝突発）＋ツイキャス個人1件 | yt-dlpで直近配信日を実測 |
| 24時間配信は海外のみ（Taronga Zoo豪=不安定、Angel Valley Farmラトビア等） | 実測・現地サイト確認 |

**→ 修正後コンセプト：「切替ビューア」ではなく「今、カピバラに会える」ハブ。**
ライブは「チャンネル単位のライブ検知→開催中だけ表示、なければアーカイブ・海外24/7へ誘導」の動的モデルにし、**施設マップ＋温泉カレンダー＋鮮度の高い施設情報を恒常的な主役**に置く。これは規約面（YouTube埋め込みページに独自コンテンツ必須）とも整合する。

## 3. 提供価値・差別化（競合が持たないもの）

1. **カピバラ特化**（世界的に空白ポジション）
2. **温泉イベントカレンダー**（全国の開催期間を横断表示。「開催中／まもなく終了」の動的表示。競合に存在しない）
3. **鮮度**（閉園・休止・飼育終了を反映。上位記事は2023年のまま閉園施設を掲載中→ここで勝つ）
4. **稼働状態の自動チェック**（競合まとめサイト共通の弱点「死んだカメラの放置」の裏返し）
5. **日本語×モダンUI**（既存の施設一覧はテキストのみの旧式）

## 4. 機能要件

### 4.1 MVP（初回リリース）

**F-1. ライブ・映像ハブ（トップ）**
- F-1-1. 登録チャンネル（国内3〜5＋海外2〜3）の**ライブ検知**を行い、配信中のものを最上部に「🔴 LIVE」表示（クリックでYouTube埋め込み再生）
- F-1-2. ライブが無い時間帯は、**海外24/7配信**（Taronga等・稼働確認済みのもの）と**厳選アーカイブ**（露天風呂LIVE・池掃除等）を表示し、「常に何か見られる」体験を担保
- F-1-3. 各配信に施設名・見どころ・配信傾向（例:「冬の露天風呂シーズンにライブ増加」）の独自解説を併載（YouTube規約対応の中核）
- F-1-4. 埋め込み不可・停止中の配信は「YouTubeで見る」外部リンクにフォールバック。稼働状況（最終確認日）を明示

**F-2. 全国カピバラマップ＆施設一覧**
- F-2-1. 地図＋一覧のハイブリッド表示。都道府県/地方でフィルタ
- F-2-2. 絞り込み: 温泉イベントあり／ふれあい・餌やり可／カフェ／ライブ配信あり
- F-2-3. 閉園・休止情報の明示（例: アロハガーデンたてやま=2025年3月閉園）

**F-3. 施設詳細ページ（MVP: 主要30〜40施設）**
- F-3-1. 基本情報: 所在地・料金・開園時間・公式リンク・アクセス
- F-3-2. カピバラ情報: 頭数/個体名（判明分）・ふれあい/餌やり・温泉イベントの今季期間と時間
- F-3-3. 収益導線: 「チケットを探す（アソビュー!等）」「近くの宿を探す（楽天トラベル/じゃらん）」
- F-3-4. 情報の最終確認日を表示（鮮度の可視化）

**F-4. カピバラ温泉カレンダー**
- F-4-1. 全国の露天風呂イベント期間を横断カレンダー/タイムライン表示（例: 伊豆シャボテン 2025/11/22〜2026/4/5、長崎バイオパーク 11/26〜3/1）
- F-4-2. 「開催中」「まもなく開始/終了」バッジ
- F-4-3. 特集: 「カピバラの長風呂対決」（全国5園同日開催・例年1月）等の横断イベント

**F-5. 記事コンテンツ（MVP: 8〜12本）**
- SEOサジェスト実測に基づくテーマ: 「カピバラ温泉はいつから？全国まとめ」「関東でふれあえる施設」「カピバラカフェ料金比較」「カピバラの生態Q&A」等
- AdSense審査要件（オリジナル記事10本以上・1,000字以上）を兼ねる

**F-6. 基盤ページ**
- プライバシーポリシー／運営者情報／お問い合わせ（審査・信頼性要件）

### 4.2 v1.1以降（MVP後）
- 新着ライブのSNS/RSS通知、LINE連携
- 施設データの全国網羅拡張（90〜150件）
- 診断コンテンツ「あなたに似てるカピバラは？」（SNS集客装置）
- 訪問記録（行った施設チェック）等のライト機能
- PWA化（ホーム画面追加・アプリ的体験。ストアアプリはコストがかかるため対象外）

### 4.3 スコープ外（明示）
- 自前カメラの設置・独占配信（zoolife型サブスク）
- ネイティブアプリ（App Store/Google Play。年会費が必要なため）
- ユーザー投稿・コミュニティ機能（当面。運用コストと権利リスク）

## 5. コンテンツ・データ要件

**D-1. 施設DB（自作）**
- 情報源: 網羅リスト（渡辺克仁氏リスト約150件・カピバラJP約90件）で候補を洗い出し→**各施設の公式サイトを一次情報として自力で裏取り**（丸写し禁止・著作権配慮）
- 項目: 施設名/種別/都道府県/緯度経度/料金/温泉イベント(期間・時間)/ふれあい可否/ライブ配信有無/公式URL/最終確認日/閉園・休止フラグ
- MVPは詳細30〜40件＋簡易リスト（残りは名称+公式リンクのみ）で開始

**D-2. 配信チャンネルDB**
- 国内: 長崎バイオパーク／伊豆シャボテン／池田動物園／埼玉こども動物自然公園（＋ツイキャス個人は掲載許諾を取れた場合のみ）
- 海外: Taronga Zoo、Angel Valley Farm（ラトビア）、Riga Zoo（季節限定・方式要確認）
- 項目: チャンネルID/施設/配信傾向/埋め込み可否（実機確認済みフラグ）/見どころ

**D-3. 温泉イベントデータ**
- 毎シーズン（秋口）に各園の公式発表を確認して更新。年1回の集中更新＋随時修正の運用

## 6. 非機能要件

**N-1. コスト**: ランニングコスト0円を基本（後述の費用方針の決定事項あり）
**N-2. 技術基盤（リサーチで検証済みの無料構成）**
- ホスティング: **Cloudflare Pages 無料枠**（広告・商用利用可、帯域無制限。Vercel無料枠は広告禁止のため不採用）
- ライブ検知: **GitHub Actions定期実行**（RSSで動画ID収集→YouTube Data API `videos.list`でライブ判定→静的JSON更新。1日約24ユニットで無料枠10,000の範囲内。60日無コミットで停止する仕様へのkeepalive対策を含む）
- サイト本体: 静的サイト（ビルド時生成＋クライアントでJSON読込）。DBはリポジトリ内のJSON/YAMLで管理

**N-3. YouTube規約遵守（必須）**
- 埋め込みプレイヤーのみのページに広告を置かない（全ページに独自コンテンツ併載）
- 広告視聴を再生条件にしない／プレイヤーへのオーバーレイ禁止
- 掲載前に各チャンネルの埋め込み許可を実機確認。不可はリンク方式に切替

**N-4. 性能・品質**: モバイルファースト（想定流入はSNS/スマホ検索が主）、Core Web Vitals良好（静的サイトで担保）、ダークモード対応
**N-5. 運用**: 更新は基本自動（ライブ検知）＋季節更新（温泉期間・年1回集中）。個人が趣味時間で回せる運用量に抑える

## 7. 収益化要件

| 手段 | 審査 | 導入時期 | 備考 |
|---|---|---|---|
| 楽天アフィリエイト（グッズ＋楽天トラベル） | なし | **MVPから** | 報酬は楽天キャッシュ中心 |
| A8.net → じゃらん/アソビュー!提携 | 登録審査なし・提携は個別 | MVPから申請 | 施設詳細→チケット/宿が本命導線 |
| 投げ銭（Ko-fi=単発手数料0% または OFUSE=日本語） | なし | MVPから | 「カピバラおやつ代」ボタン |
| Google AdSense | 独自ドメイン実質必須＋記事10本以上 | **成長後**（費用方針の決定次第） | 埋め込み主体では落ちるため記事併設が前提 |
| Amazonアソシエイト | 180日で3成約 | 記事が育ってから | |

- 収益の柱は「**施設詳細→チケット・宿アフィリエイト**」と位置づける（単価・成約率で広告より優位）。
- 全ページにアフィリエイト表記（景表法ステマ規制対応）を掲載。

## 8. リスクと対策

| リスク | 対策 |
|---|---|
| 配信の休止・閉園（供給が細る） | チャンネル単位の自動検知＋アーカイブ/海外併載で「ゼロ表示」を回避。稼働状況の定期監視自体を差別化に転化 |
| YouTube規約変更・埋め込み無効化 | リンク方式へのフォールバックを最初から実装。規約は安全側（Developer Policies準拠）で運用 |
| ニッチゆえ収益が小さい | 広告依存にせず旅行・チケットアフィリエイトを主軸に。将来はオリジナルグッズ（POD）へ拡張可能な設計 |
| 施設情報の陳腐化 | 「最終確認日」表示で誠実性を担保。季節集中更新の運用ルール化 |
| 検索需要の季節性（冬ピーク） | 夏はライブ/カフェ/ふれあい系コンテンツ、冬は温泉カレンダーと役割分担 |

## 9. 決定事項（2026-07-09 ユーザー承認）

**Q1. 費用方針 → A案（完全無料で開始、軌道に乗ったら段階追加）で決定**
- `*.pages.dev`サブドメインで公開。楽天アフィリエイト/A8/投げ銭はMVPから開始
- 成長後: 独自ドメイン（約1,500円/年）を同一Cloudflare Pagesプロジェクトに追加→旧URLからリダイレクト→記事10本以上の状態でAdSense申請
- **設計要件**: サイトURLは設定1か所（環境変数/設定ファイル）で切替可能にし、将来のドメイン移行コストを最小化する

**Q2. MVP機能範囲 → F-1〜F-6の構成で承認**

**Q3. ツイキャス個人配信 → 当面は掲載しない**（動物園・公式チャンネルのみで開始。サイトが形になった後、掲載許諾を取ってから検討）
