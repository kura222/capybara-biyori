## 0. コンセプト

**「温泉宿の雑誌のような、カピバラのポータル」**
- 世界観: 温泉旅館の上質さ（明朝・生成り・罫線・余白）× カピバラの親しみ（丸み・暖色・マスコット）
- 参照軸: 星野リゾート/万平ホテル（上質の定数）＋ すみだ水族館（親しみの作り方）＋ TRANSIT（雑誌的カード）＋ Headspace（暖色の癒し）
- 受賞サイトの鉄則「**1画面で大声は1つ**」「シグネチャーモーメントは1点豪華主義」

## 1. 禁止リスト（AIっぽさの排除・違反は差し戻し）

1. **絵文字のアイコン・装飾代用**（全廃。SVGアイコンに置換）
2. 紫〜青の意味のないグラデーション、グラデ玉、ガラスモーフィズム
3. 「hero→均一3枚カード」の定型骨格（セクションごとにレイアウトのリズムを変える）
4. 全カード一律の1pxグレー枠＋`shadow-lg`級の既定影、カード左端の色付きボーダー
5. 純白`#fff`背景・純黒`#000`テキスト（面はすべて生成り系、文字は焦げ茶系）
6. 均一なborder-radius（用途別スケールを使う）・全要素カード化
7. バウンス系イージング、一律フェードイン、hoverで暗くするだけの表現
8. 中身のない汎用コピー（「もっと便利に」等）。文言は具体で書く

## 2. カラートークン（ライト）

```css
:root {
  /* 面（純白禁止・生成りの階調） */
  --bg: #F7F2E9;            /* ページ地=生成り */
  --surface: #FDFBF6;       /* カード面（地との差はわずか） */
  --surface-soft: #F1E9DC;  /* 帯・ソフト面 */
  --surface-deep: #EAE0D0;  /* 強調帯・フッター */
  /* 文字（3階層・焦げ茶の墨） */
  --text-1: #3A2E22;
  --text-2: #6E5F4E;
  --text-3: #9B8B77;
  /* 罫線 */
  --line: #E4DAC8;          /* ヘアライン */
  --line-strong: #C9B99F;
  /* アクセント（面積5%未満・淡色ペア体系） */
  --accent: #C9682F;        /* 湯けむりテラコッタ（くすみ寄り） */
  --accent-strong: #A85320; /* hover/active・Duolingo式ボタン影 */
  --accent-soft: #F6E3D2;   /* バッジ地・選択状態 */
  --green: #5F7D54;         /* 開催中・営業中（くすみ苔色） */
  --green-soft: #E4EBDD;
  --live: #C2452F;          /* LIVE（くすんだ朱・純赤禁止） */
  --live-soft: #F7DFD8;
  /* 影（黒影禁止・背景と同色相。SmartHR式に段数固定） */
  --shadow-1: 0 1px 2px hsl(33 30% 30% / .06);
  --shadow-2: 0 2px 4px hsl(33 30% 30% / .06), 0 6px 16px hsl(33 30% 30% / .08);
  /* 影の用途規定: 1=浮き要素(ヘッダー影は不可・罫線で区切る), 2=hover時のカード/ドロップダウンのみ。それ以外は影なし */
}
```

## 3. カラートークン（ダーク・Linear方式）

「色反転」ではなく**同色相でLightnessだけ落として面4段**。彩度は微減。

```css
:root[data-theme="dark"] {
  --bg: #1C1610;  --surface: #262019;  --surface-soft: #322A20;  --surface-deep: #14100B;
  --text-1: #F2EADF;  --text-2: #C3B4A0;  --text-3: #8E7F6C; /* 純白禁止 */
  --line: #3C3225;  --line-strong: #554835;
  --accent: #E0824A;  --accent-strong: #C9682F;  --accent-soft: #3E2B1B;
  --green: #7C9A6F;  --green-soft: #2A3323;
  --live: #E06A52;  --live-soft: #42251E;
  /* ダークでは影を使わず面の明度差で階層化（Linear） */
  --shadow-1: none;  --shadow-2: 0 0 0 1px var(--line);
}
```

## 4. タイポグラフィ（実測値ベースの定数）

| 役割 | フォント | 用途 |
|---|---|---|
| 見出し | **Shippori Mincho B1**（600/700） | h1〜h3、ヒーローコピー（星野リゾート実測と同部品＝温泉宿の気配） |
| 本文/UI | **Zen Kaku Gothic New**（400/500/700） | 本文・ナビ・ボタン・キャプション |
| 数字/欧文ラベル | **Fraunces**（400/600、latinのみ＝軽量） | 日付・時刻・料金・セクション番号「01」・「LIVE」等の欧文小ラベル（星野「数字専用書体」方式） |

```css
body    { font-size: 16px; line-height: 1.75; letter-spacing: .04em; }  /* 万平150/170%系の読み物値 */
h1,h2,h3{ font-feature-settings: "palt"; letter-spacing: .06em; line-height: 1.35;
          word-break: auto-phrase; text-wrap: balance; }               /* 非対応ブラウザでは無害に無視される */
h1      { font-size: clamp(1.75rem, 1.2rem + 2.8vw, 2.75rem); }        /* h1:本文≒3:1・vw連動 */
.label  { font-family: Fraunces; letter-spacing: .12em; text-transform: uppercase; font-size: .8125rem; } /* 小ラベルは字間広く */
```

- Google Fonts（v2 API・preconnect・display=swap・使用ウェイトのみ）。まず配信版で実装し、paltが効かない場合もletter-spacingで成立する設計にする
- 本文はベタ組み原則（text-wrapの調整は見出しのみ）

## 5. 形状・アイコン・部品

**角丸スケール（用途固定・SmartHR式）**: `--radius-s: 6px`（ボタン・入力・タグ）／`--radius-m: 12px`（カード・埋め込み）／`--radius-full: 9999px`（ピル・ステータスバッジ）。これ以外の値を発明しない。

**アイコン: Phosphor Icons（MIT）で絵文字全廃**
- `astro-icon` + `@iconify-json/ph`。通常=regular、選択/強調=duotone または fill（Duolingoの淡色ペアと同思想）
- サイズは1em基準でテキストに揃え`currentColor`。「角丸タイル上に中央配置したアイコン」はAIテルなので禁止

**ボタン**
- 主CTA（1画面1個まで）: `--accent`地×白文字 + `box-shadow: 0 3px 0 var(--accent-strong)` + activeで`translateY(3px)`＆影なし（Duolingo式の控えめ版）
- 副ボタン: `--surface`地＋1px `--line-strong`枠＋文字`--text-1`。hoverで枠と文字が`--accent`に

**カードの2流派（用途固定）**
- (a) **編集的カード**（施設一覧・記事）: 罫線1px `--line`＋角丸`--radius-s`＋影なし。hover=画像1.03倍ズーム＆罫線・見出しが`--accent`化（「薄暗くするだけhover」禁止）
- (b) **親しみカード**（ライブ・カレンダー・マスコット系）: 面色`--surface-soft`系＋角丸`--radius-m`＋影なし。hover時のみ`--shadow-2`
- 写真主体のカードは Airbnb式「角丸写真＋枠線影なし＋テキスト3行」も可（P1施設カードで採用予定）

**セクション見出しの型（雑誌的・全セクション統一）**
```
01 — LIVE            ← Fraunces .label（字間.12em）＋左に短い罫線
いま配信中のカピバラ   ← Shippori Mincho h2
```

**区切り**: ベタ1本線でなく「両端フェードのヘアライン」または生成り面の明度差。セクションpaddingは均一にせず、重要度でリズムを付ける（`--space-section-l/m/s`の3種）

## 6. 質感（3点セット）

1. **off-white面**（トークンで担保済み）
2. **微グレイン**: SVG `feTurbulence`（baseFrequency 0.65・data URI・opacity 5〜6%・mix-blend-mode: multiply）をヒーローと`--surface-deep`帯にのみ適用。全面適用禁止
3. **湯けむりモチーフ**: 細線（1.5px・`--line-strong`）の湯気カーブSVGをヒーロー・空状態・フッターに小さく。和柄（青海波等）を使う場合は不透明度2〜3%の背景ワンポイントまで

## 7. マスコット（カピバラSVG）

- Headspace式の制約: **単純図形に還元**（丸い輪郭＋小さい耳＋四角い鼻先＋点の目＋頬に湯気 or 頭に温泉タオル）。フラット塗り・限定パレット（`--accent`系3色以内）・線なし or 単色線
- 出す場所: **空状態・完了・季節演出・フッターのみ**（情報密度の高い一覧・地図には出さない＝Duolingo運用則）
- 空状態の型（NN/g）: 固有ビジュアル＋理由の1行＋次の行動導線。「準備中」バッジだけの表示は禁止

## 8. モーション（3トークンで完結）

```css
--motion-fast: 150ms cubic-bezier(0.23, 1, 0.32, 1);   /* hover/press */
--motion-base: 250ms cubic-bezier(0.23, 1, 0.32, 1);   /* カード・開閉 */
--motion-slow: 400ms cubic-bezier(0.32, 0.72, 0, 1);   /* ドロワー等（当面未使用可） */
```
- animateは`transform`/`opacity`のみ。ease-in禁止。バウンス禁止
- reveal: 「表示済みが既定」で、`prefers-reduced-motion: no-preference`内でのみopacity+translateY(12px)を1回。keyboard起点はアニメなし
- ボタンpress=`scale(0.97)` 160ms

## 9. レイアウト原則

- コンテナ: 本文系 max-width 720px / 一覧系 1080px / ヒーロー系 1200px。**全セクション同幅にしない**
- ヒーロー（シグネチャーモーメント）: 生成り面＋タイポ型（明朝の大コピー＋Fraunces縦ラベル＋湯気の細線＋グレイン）。将来P3で「ライブ映像フルブリード＋明朝コピー1行＋LIVE小ラベル」に差し替えられるDOM構造にする。**ボタンを2個並べて終わりにしない**
- 一覧のリズム: ライブ=大1枚＋小リスト（TRANSITの特集型）／アーカイブ=番号付き編集リスト（01,02,03…Fraunces数字）／フィード=横スクロールカード。**均一グリッドの反復を避ける**
- ナビは目的起点の文言（すみだ式）: 「いまを見る」「会いに行く」「温泉ごよみ」「よみもの」
- フッター: サイトマップ型＋ヘアライン区切り＋最後に小さくマスコット

## 10. 検証則（実装後に自己チェック）

1. **squintテスト**: サムネイル縮小しても階層が読めるか
2. **色を抜いても成立するか**（任天堂）: グレースケールで階層が保たれるか
3. **1画面1大声**: 各ビューで最も目立つ要素は1つか
4. 絵文字が1つも残っていないか（`grep`で確認: 🐹♨️🗺️📝🔴🌿等）
5. ライト/ダーク両方で罫線・影・アクセントが破綻していないか
6. `prefers-reduced-motion`で動きが止まるか
7. コントラストAA（特に`--text-3`と`--accent`の上の白文字）
8. Lighthouse Performance/SEO 90+維持（フォント追加後も）
